# Fonts served by this application

Both faces are served from this host rather than from a font CDN: a counter in a warehouse on a
thin line should render the same as a desk in the office, and a third party that can serve a font
is a third party that can serve something else.

## Inter

`inter-latin-variable.woff2` — Inter, variable weight axis 100–900, Latin subset.
